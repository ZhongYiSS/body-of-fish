# 本鱼陪伴 · 使用说明（0.5.x）

> 桌面上的一只小鲸鱼娘：会说话、会看你屏幕、会自己找话说；
> 接上 DeepSeek Harness（下面简称 DSH）之后，还能替它念回复、替它看图。
>
> 这份只讲**怎么用**。要改代码 / 排错，看同目录的《注意事项》。

---

## 一、她是什么

- 一个**独立的小窗口**，住在桌面角落：可以拖、可以扔，会撞墙弹一下。
- **0.5.0 起只有桌面小窗**：DSH 网页版里那套宠物面板已经整批删掉了，她不再是一个网页插件。
- 她自己连 AI（本地或云端都行），不依赖 DSH 也能聊天、能看屏幕、能出声。

## 二、第一次启动

1. 用**桌面快捷方式**「本鱼陪伴」启动。⚠️ 别双击安装目录里的 `BodyOfFish.exe`，原因见第九章。
2. 她出现在屏幕角落，托盘里多一个小图标。
3. 想改外观 / 模型 / 声音：**托盘图标右键 → 设置…**（也可以右键她 → 设置…）。
4. 想接 DSH：看第七章。
5. **只能开一只**：已经在跑的时候再点快捷方式，会弹一句「本鱼已经开着一个了，这个就不开了」。
   同时开两只抢声音、抢配置，这个框是拦你的，不是报错。

## 三、右键菜单

右键点她，从上到下：

| 菜单 | 干什么 |
| --- | --- |
| `状态 ▸` | 她的几盏灯和开关：`嗓子`（四块循环切：模型直连 → 本地 TTS → Windows 系统 → Edge 在线）、`眼睛`（识图用哪个模型）、`歌词`（开关）、`联网查`（开关，默认开）、`接入`（接 DSH 的开 / 关 / 选会话 / 装插件） |
| `取景 ▸` | 她看屏幕时的取景方式：`全屏` / `自动`（推荐）/ `窗口`（只截你选定的那个窗口）；最后一项`看他看到的（记录目录）…`会打开记录文件夹 |
| `陪伴 ▸` | 一直盯着你屏幕陪着：`开/关`、`轻`（约 2 张/分）、`正常`（4 张/分）、`密`（7.5 张/分）、`会出声`开关 |
| `看一眼 ▸` | 只看一次：`开（定时）`、`现在看一眼`、`自定义时间…`（**20–600 秒**） |
| `碎碎念 ▸` | 自己找话说：`自动开/关`、`打开池子`、`间隔（N 秒）…` |
| `说一句` | 让她现在随口说一句（不会打断你正在跟她说的话） |
| `看一眼` | 立刻看一眼屏幕，然后说一句 |
| `动作` | 换一个待机动作 |
| `重启配置` | 改完配置文件不用重启整个程序，点这个重新加载 |
| `点击穿透` | 打开后鼠标能穿过她点到后面的东西（再点一下关） |
| `退出` | 退出程序（托盘图标右键也有） |

> 菜单里带 `▸` 的是一层子菜单，点一下展开。

## 四、几个功能分别怎么用

### 4.1 聊天

- **按 `Alt+T` 按住说话**，松开就发；说完她回话（文字 + 出声）。
- 也可以左键点她一下，她随口应一句。
- 她说话很短（**一句 20 字以内**），是陪你闲聊，不是念屏幕内容。
- **让她记事**：聊天里说「记住：我不吃香菜」，她会存成一条长期记事，以后自动想起来。设置页也能手填。
- **联网查**：问她「帮我查一下 XX」时她会自己上网搜（走必应 / 搜狗 / 360 / 百度），查到用她自己的话讲，不照念标题。
  状态子菜单可以关掉这一项。

### 4.2 一眼看（只看一次 / 定时）

- 右键 → `看一眼 → 现在看一眼`：立刻看一眼，说一句。
- 右键 → `看一眼 → 开`：每 **20–600 秒**看一次（`自定义时间…` 里填秒数）。
- **默认是关的**，用完记得关，省 token。

### 4.3 陪伴（一直陪着）

- 右键 → `陪伴 → 开`，她开始以固定频率看你屏幕，在心里攒笔记，攒到能搭一句话的时候才开口。
- 频率三档：`轻` / `正常` / `密`（一分钟最多几张，菜单上标着）。
- **取景**决定她看哪儿：`全屏` 全屏截图 / `自动` 自动挑你正在用的窗口（推荐）/ `窗口` 只截你在设置页里选定的那个窗口。
- **默认是关的**（哥哥 11-16 定的：怕莫名其妙消耗）。开了以后重启会自己接着开。
- `取景 → 看他看到的（记录目录）…`：打开她的现场记录——每张截图 + 每轮笔记，
  能亲眼核对「她到底看到什么、为什么说那句话」。

### 4.4 碎碎念（自己找话说）

- 从「碎碎念池子」里抽卡片自己说，**纯本地、不花 token**、声音最低级，**不会打断任何人**。
- 间隔可调；池子可以在设置页里的「碎碎念」区域编辑。

### 4.5 嗓子（四块）

声音分四套，右键 `状态 → 嗓子` 一点就循环切，设置页里是四个页签：

| 块 | 用在哪 | 填什么 |
| --- | --- | --- |
| `模型直连` | 用云端模型的语音接口 | 地址 / 模型 / 密钥 |
| `本地 TTS` | 本机 GPT-SoVITS 之类 | 本地服务地址（默认 `http://127.0.0.1:9880`）+ 模型名 |
| `Windows 系统` | 系统自带语音（SAPI），不联网 | 选一个系统语音就行 |
| `Edge 在线` | 微软在线语音 | 选音色 |

- **切块不会丢设置**：四块各存各的，切回来还是原来那份（0.5.x 修的）。
- 音量：设置页「模型 → 声音」里有滑杆（0–100），只影响播放，不改合成。

### 4.6 眼睛（识图）

- 她「看」屏幕其实是**截图 + 识图模型**：看出你用什么软件、在干什么、有没有报错。
- 识图模型在设置页「模型 → 看图」里填（本地 / 云端都行）。
- 她**不读 DOM、只看看当前这一屏**，所以长文章、弹幕、滚动字幕是看不清的。

### 4.7 歌词

- 独立小条，跟音乐播放器联动（网易云），**不占说话气泡、不花 token**。
- 右键 `状态 → 歌词` 开关。

## 五、快捷键

| 键 | 干什么 |
| --- | --- |
| `Alt+T` | 按住说话，松开发送（再说一次可打断她） |
| `Alt+G` | 看一眼屏幕 |
| `Alt+S` | 说一句 |

快捷键可以在设置页「其他」里改。

## 六、设置页

右键她 / 托盘图标 → `设置…`，一页改完，四个大项页签：

| 页签 | 里面有什么 |
| --- | --- |
| `外观` | 名字、大小、边距、重力 / 弹力 / 摩擦力、字体、待机动作、提示气泡的字号与位置（可拖） |
| `模型` | 模型方案（一页签一套，整套切换：对话 / 看图 / 声音各一套地址+模型+密钥）、对话模型、看图、声音（四页签 + 音量） |
| `陪伴` | 陪伴的取景、窗口下拉、频率、20 个物理调参、三套提示词、回看模板、结果面板 |
| `其他` | 全局快捷键、其他开关 |

- 改完点「保存」立刻生效（少数项要重启小窗，页面会提示）。
- **模型方案**：可以存好几套（本机 / 云端 / 别的服务），点页签整套切，切换前会自动把当前这套存回去。

## 七、接入 DSH

接上之后她多两件事：

1. **替 DSH 念回复**：DSH 里的回复会投到她这里，念出来 + 冒气泡。
2. **替 DSH 看图**：DSH 收到图片时交给她识图，结果投回会话。

装法：右键 → `状态 → 接入 → 装插件到 DSH…`，按提示重启 DSH；
之后 `状态 → 接入 → 开`，`选会话…` 里点一行就接上那个会话。

> 投进 DSH 的每一句都带信封：`（桌宠看了一眼屏幕 · 14:32）` + 内容 +`（以上是桌宠的转述，不是他说的话）`，
> 这样 DSH 那边的模型不会把她的话当成你说的话。

## 八、数据存在哪

全在**你自己的用户目录**下，不写在安装目录里：

```
%USERPROFILE%\.dsh\body-of-fish\
├─ main-config.jsonc      全部设置（含密钥，别外传）
├─ ai-profiles.json       模型方案
├─ memory\
│  ├─ session.json        当前这段对话（聊满 5000 字自动换卷）
│  ├─ sessions\           旧卷（不删，可搜）
│  ├─ cards.json          长期记事（「记住：…」）
│  └─ <日期>.json         每天的记忆流水
├─ shots\
│  ├─ look\               看一眼的截图（滚动 12 张，旧的自己覆盖）
│  └─ watch\              陪伴看到的那一张（保留 3 天 / 上限 150MB）
├─ notes\
│  └─ watch\              陪伴笔记 <日期>.jsonl + scene.json
│     ├─ subtitles\       B站字幕原文（30 天）
│     └─ story\           整片剧情梗概（30 天）
├─ logs\
│  ├─ mouth.log           嘴：每次说话、播放、气泡、/say-loud（每行带 [speak]/[play]/[bubble]）
│  ├─ sense.log           耳眼：听和看进来时的事件
│  └─ mind.log            想：谁掐了谁、联网查、摘要与换卷（每行带 [mind]/[search]/[summarize]）
└─ memes\                 表情包
```

> 0.5.x 以前的老结构（`companion-shots\`、`logs\陪伴\`）**启动时会自动搬一次**到 `shots\` / `notes\`，
> 搬完写 `layout.json` 做标记；旧实例又写出来的那几个文件，下次启动照样会跟着搬走。

- **卸载时**会问要不要一起删配置（默认不删）。
- **备份**：整个 `.dsh\body-of-fish` 拷走就是完整备份。

## 九、启动与快捷方式（重要）

### 9.1 为什么别双击 exe

`BodyOfFish.exe` 直接双击会**跳过快捷方式里带的参数**（`--no-sandbox` 等），
在部分机器上会起不来、或者起一半没窗口。**请始终走快捷方式。**

### 9.2 快捷方式丢了怎么办

右键桌面 → 新建 → 快捷方式，目标填：

```
"<安装目录>\BodyOfFish.exe" --no-sandbox --disable-gpu-sandbox --in-process-gpu
```

安装目录在安装时选过（默认在 `%LOCALAPPDATA%\Programs\body-of-fish`）。
装完安装器一般已经帮你建好桌面和开始菜单的「本鱼陪伴」。

## 十、常见问题

| 现象 | 怎么办 |
| --- | --- |
| 双击没反应 / 一闪就没 | 用快捷方式启动；还不行看《注意事项》第六章「要管理员」那条 |
| 说「本鱼已经开着一个了」 | 已经有一只了。去托盘退掉旧的，再开 |
| 没声音 | 设置页 → 模型 → 声音，看四块里当前那块地址/模型填了没；再看 `logs\mouth.log` 里 `[play]` 那几行 |
| 不说话了 / 一直【在想】 | 看她是不是正在录音（`Alt+T` 一次）；超时 45 秒会自己恢复 |
| 陪看没反应 | 陪伴默认关；先 `陪伴 → 开`，并确认调的是「取景」不是「全屏」挡了窗口标题 |
| 设置保存不了 | 页面会点名哪个字段越界（比如「出错的字段：hintX」），按提示改 |

## 十一、卸载

- 控制面板 / 设置 → 应用 → 「本鱼陪伴」→ 卸载。
- 卸载时会问要不要删配置：**选「否」**，下次装回来记忆和设置还在。
