# 本鱼陪伴 0.4.1 · 使用说明

> 这是在桌面上陪你干活的一只小鲸鱼娘。
> 她会说话、会看你屏幕、会自己找话说，接上 DSH 以后还能替它念回复、看图片。
> 这份只讲**怎么用**；给会改代码的鱼看的那份叫《注意事项》。

## 一、先认识她

- 桌面上多一个会动的小人（可以拖、可以扔、会撞墙弹一下）。
- 右键点她 → 一整套菜单；左键点她 → 冒一句话或表情。
- 不想要了：退出请走托盘图标右键 → 退出，别直接删文件夹（配置会写在用户目录里）。

## 二、第一次启动

1. 从安装目录或**桌面快捷方式**启动（`本鱼陪伴`）。⚠️ 不要双击 `BodyOfFish.exe`，原因见第四章。
2. 启动后她会出现在屏幕角落，托盘里多一个图标。
3. 想改外观、模型、声音：**托盘图标右键 → 设置…**，一页全部改完。
4. 想接 DSH：看第三章第 7 节。

## 三、日常怎么用

### 3.1 右键菜单一览

右键她，从上到下大致是：

| 菜单 | 用来干嘛 |
| --- | --- |
| `状态 ▸` | 四个开关：陪伴 / 嗓子 / 眼睛 / 歌词；以及 **接入 DSH** 的装插件、开关、选会话 |
| `看一眼` | 立刻让她看一眼屏幕，说一句 |
| `陪伴 ▸` | 定时看她一眼：1 / 2 / 3 / 5 分钟，或自定义；也能关 |
| `对话` | 打开聊天窗，跟她聊天 |
| `碎碎念 ▸` | 自己找话说：开/关、间隔 1 分钟~1 小时、打开池子、自定义秒数 |
| `重载配置` | 改了配置文件不用重启，点它 |
| `点击穿透` | 让她「变透明」：点她身上的位置会点到后面的窗口 |
| `动作 ▸` | 各种小动画（摸头、跳一下之类） |
| `更多 ▸` | 开关（显示位置）、回到初始位置、第三方项（设置…） |

> 菜单里带 ✓ 的，就是**当前正开着**的那一项。

### 3.2 跟她聊天

1. 右键 → `对话`，弹出聊天窗。
2. 输入后回车发送。她会按设置页里配的模型和人格回你。
3. 如果配了表情包，她念完约 1 秒会弹出对应的表情图。
4. 关掉聊天窗 = 结束对话，不会影响她继续陪伴。

### 3.3 让她陪你（定时看一眼）

- 右键 → `陪伴 ▸` → 选 `1/2/3/5 分钟`，她会按这个节奏看你的屏幕。
- 每次看的结果：一句话告诉你「现在在干嘛 / 有没有报错」。
- 你说「自定义…」就自己填分钟数。
- 如果连着两次看到画面没变化（比如你在看同一个页面发呆），她会自己停，省得一直打扰你；需要时重新开。
- 想停：`状态 ▸ 陪伴 · 关`，或 `陪伴 ▸ 关陪伴`。

### 3.4 让她自己找话说（碎碎念）

- 打开：`碎碎念 ▸ 自动开`。她每隔一段时间从「池子」里挑一句说。
- 调间隔：菜单里 1 / 5 / 15 / 30 / 60 分钟，或 `自定义（N 秒）`。
- 改句子：`碎碎念 ▸ 打开池子`，会打开那个文件；按里面示例的格式加句子，保存后点 `重载配置` 即可。

### 3.5 让她出声（嗓子）

- 三档：`本地`（用本机的 TTS 服务）/ `云`（用云端 TTS）/ `关`。
- 在设置页「声音」里选**发声协议**：
  - `system`：用 Windows 自带语音，最稳，推荐先试它；
  - `openai`：OpenAI 兼容的云端 TTS；
  - `edge`：Edge 在线语音，偶尔会没声音（网络问题），没声音就换 `system`。
- 正在念的时候想打断：开始新的输入（按住说话快捷键、新点一次「看一眼」）会自动停；没有单独的「停止朗读」菜单。
- 云端 TTS 的接口地址和密钥可以单独填；**留空就用对话模型那一套**。

### 3.6 让她看屏幕（眼睛）

- 三档：`本地`（本机视觉模型）/ `云` / `关`。
- 本地：填本机视觉服务的地址（例如 `http://127.0.0.1:1234/v1`）和模型名。
- 云端：填接口地址和密钥；留空就用对话模型的。
- 想看的时候：右键 → `看一眼`。她会告诉你：开的什么窗口、大概在干嘛、有没有报错。
- 眼睛没配好时她不会乱猜，会安静地不提。

### 3.7 接入 DSH（让她替 DSH 说话、看图）

**装插件（只做一次）**

1. 右键 → `状态 ▸ 接入 · 装插件到 DSH…`，等提示「桥插件装进 DSH 了」。
2. 重启一次 DSH（关掉再打开）。身体不用重启。

**接上会话**

- 右键 → `状态 ▸ 接入 · 选会话…`，会打开一个网页，点一行就接上那个会话。
- 想断开/换：`状态 ▸ 接入 · ✓ 开（会话名）` 点一下可关；或在选会话页换。

**接上以后会发生什么**

- DSH 每回完一段话，她会把最后那段压成两句以内冒个泡；如果嗓子开着，还会念出来。
- 你在身体聊天窗里说的话，会像打字一样出现在 DSH 那个会话里。
- DSH 里收到的图片，会转给她看，她看完把描述写回会话。
- DSH 关着的时候，菜单会显示 `接入 · 关`，这是正常的；DSH 打开后会自动回来。

### 3.8 设置页（一页改完）

**托盘图标右键 → 设置…**，八组：

1. **这只宠物**：名字、大小、是否在桌面显示、固定不动、贴边角落、左右/上下边距、只留在当前屏幕。
2. **人格（它是谁）**：人设提示词——碎碎念、看一眼、对话共用这一份；清空保存 = 恢复默认。
3. **气泡字体**：字体、字号、字号跟不跟宠物大小。
4. **手感**：重力、弹性、摩擦、投掷力度、顶部反弹。
5. **对话模型**：协议（OpenAI 兼容 / Anthropic）、输出上限、接口地址、模型名、密钥、启用开关。
6. **看图**：后端、本地地址、模型名、云端地址/密钥（留空沿用对话模型）。
7. **声音**：后端、发声协议、本地地址、模型/音色、云端地址/密钥、参考音路径与文本。
8. **全局快捷键**：按住说话（默认 Alt+T）、看一眼（默认 Alt+G）、说一句（默认 Alt+S）；写成 Alt+T 这种形状，留空用默认。

改完点「保存设置」，桌面小窗会自己重启一下（约一秒），网页里的形象不受影响。

### 3.9 小动作

- 按住左键可以拖走；松手她会掉下去、弹一弹。
- 快速甩一下 = 扔出去，撞到屏幕边缘会弹。
- 点击穿透开着时，点她身上等于点后面的窗口；想点她回来，去托盘菜单关掉。

## 四、启动与快捷方式（重要，请看完）

### 4.1 为什么不能双击 exe

有些 Windows 机器上，Electron 的程序**直接双击 exe 会一闪就没**（GPU 子进程被系统拒绝）。
必须带上三个启动参数才能正常跑：

```
--no-sandbox --disable-gpu-sandbox --in-process-gpu
```

安装包创建的快捷方式已经带好了，所以你**平时只双击快捷方式**就行。

### 4.2 正常入口

1. 桌面 `本鱼陪伴` 快捷方式；
2. 开始菜单 → `本鱼陪伴`（个别机器上会被安全软件拦掉，没有就自己建，见 4.3）；
3. 安装目录里的 `pet.cmd`（双击也能起，会闪一下黑框）；
4. 命令行：
   ```
   start "" "你的安装目录\BodyOfFish.exe" --no-sandbox --disable-gpu-sandbox --in-process-gpu
   ```

### 4.3 快捷方式丢了 / 坏了，自己补

**办法一：手动建（推荐）**

1. 桌面空白处右键 → 新建 → 快捷方式。
2. 位置填（把路径换成你的安装目录）：
   ```
   "<安装目录>\BodyOfFish.exe" --no-sandbox --disable-gpu-sandbox --in-process-gpu
   ```
   ⚠️ 引号必须是英文半角；三个参数一个都不能少，写在引号**外面**。
3. 名字填 `本鱼陪伴`。
4. 右键 → 属性，确认「起始位置」是安装目录，「目标」里有那三个参数。

**办法二：重跑安装包**

直接再运行一次安装包，装到同一目录：会自动重建桌面和开始菜单快捷方式，配置不会丢。

**办法三：拿 pet.cmd 当目标**

新建快捷方式，目标填安装目录里的 `pet.cmd`（参数已经在里面了）。

### 4.4 怎么确认快捷方式是对的

- 右键快捷方式 → 属性 → 「目标」里能看到 `--no-sandbox --disable-gpu-sandbox --in-process-gpu`。
- 双击能起、不闪退。
- 反过来：双击 `BodyOfFish.exe` 会闪退——这不是坏了，是必须带参数。

### 4.5 常见错误

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 双击快捷方式也闪退 | 参数没带上 / 用了全角横线 / 路径有中文没加引号 | 按 4.3 办法一重填 |
| 快捷方式指向旧目录 | 装到新地方，快捷方式还是旧的 | 重跑安装包，或手改目标 |
| 提示找不到 exe | 安装目录被移动/改名 | 把目标改成真实路径 |
| 开始菜单没有 | 安装时被安全软件拦 | 用 4.3 办法二建一个 |
| **以管理员身份能开、普通双击没反应** | 安装盘带了 `Low` 完整性标签（Windows 会让从 Low 标记的 exe 启动的进程也跑在 Low，写不了自己的日志） | 临时：右键「以管理员身份运行」；根治：`icacls "盘符:\"` 看 `Mandatory Label`，若是 `Low`，用 `icacls "盘符:\" /setintegritylevel Medium /T /C /Q` 改回（先 `icacls "盘符:\" > 备份.txt` 留底） |

## 五、数据、备份、卸载

- 配置和记录都在：`C:\Users\你的名字\.dsh\body-of-fish\`
  （里面：`main-config.jsonc` 主配置、`logs\` 日志、表情包和语音缓存；有些机器上这个目录是指向别的盘的快捷链接）。
- 想备份：把上面整个目录复制一份保存。
- 安装目录下还有一个 `文档` 文件夹，放着《功能介绍》和《注意事项》（想改她的鱼看的那份），卸载时一起删掉。
- 卸载：控制面板 → 卸载；最后会问「要不要把配置也删掉」——
  - 想以后装回来还在：选**否**；
  - 想彻底清干净：选**是**（人格、碎碎念池、快捷键、语音缓存都会没）。

## 六、常见问题

**Q：她不说出声？**
先确认 `状态 ▸ 嗓子` 不是「关」；再进设置页把发声协议改成 `system` 试一下。

**Q：她看不见/不陪我看了？**
确认 `状态 ▸ 眼睛` 不是「关」；本地服务没开的话换成云端，或反过来。

**Q：接 DSH 后她不冒泡？**
看菜单 `状态 ▸ 接入` 是不是 `✓ 开（会话名）`；再看看 DSH 是不是开着；刚装完要重启一次 DSH。

**Q：她在说什么？听不清？**
右键 → `对话`，聊天窗里能看到完整对话；或者把气泡时间调长一点（设置页外观）。

**Q：怎么让她先闭嘴/先别动？**
`状态 ▸ 陪伴 · 关`、`状态 ▸ 碎碎念 · 自动关`，或者直接把她拖到角落、开 `点击穿透`。
