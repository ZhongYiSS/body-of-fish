表情包和碎碎念怎么改
==================

不用装插件、不用开设置页，改三个地方就够了。全都在你自己的数据目录里：

  默认位置：%USERPROFILE%\.dsh\body-of-fish\
    memes\             <- 放图片（一张图一个 png）
    main-config.jsonc  <- 找里面的 "memes" 段，这里是「有什么图 + 每张什么意思」
    碎碎念池.json       <- 挑哪句话配哪张图

改完不用重启，下一句碎碎念就用新的。


一、加一张新图（三步）
----------------------
1) 把图片放进 memes 文件夹，文件名就是它的「名字」。必须是 .png。
   例：memes\本鱼要饭.png

2) 在 main-config.jsonc 的 "memes" 段加一行（记得上一行末尾要有逗号）：
       "本鱼要饭": "端着空碗要饭，可怜巴巴",
   冒号左边 = 名字，必须和文件名一模一样（不带 .png）；
   冒号右边 = 描述，写给模型看的：她什么时候该挑这张。

3) 想让她碎碎念时说某句话配这张图，就在 碎碎念池.json 里写一条：
       { "text": "有没有吃的呀", "meme": "本鱼要饭" }

就完了。


二、描述到底有什么用
--------------------
描述不是给自己看的备注，是模型挑图的依据：
  - 碎碎念：你写死 pairing（句子里的 "meme"），描述不参与，写错也不影响；
  - 聊天配图：模型会读这份清单（名字 + 描述）自己挑，描述写得越具体越好挑。
    「端着空碗要饭，可怜巴巴」 > 「一张表情包」。


三、只让一部分图被抽到
----------------------
同一段里还有个 "memePool"：
  - 空数组 [] 或干脆不写 = 全部都能抽（默认）；
  - 写了名字，就只在里面抽，顺序就是抽取的先后：
        "memePool": ["正在思考", "急了", "本鱼要饭"]


四、碎碎念池怎么看
------------------
碎碎念池.json 是一个数组，一条一句：
    { "text": "今天也辛苦了", "meme": "哦鲸鲸" }
  - text 可以留空，那就是只发图；
  - meme 可以省，省了就随机挑一张；
  - 想整份换掉就整个文件替换，格式对就行。


五、改名、删图、换图
--------------------
  - 删图 → 那条描述就没用了，建议顺手把 "memes" 里那行删掉（不删也不报错，只是白占位）；
  - 改名 → 表里、池子里、文件名三处一起改，少改一处就配不上；
  - 换图（内容变、名字不变）→ 直接覆盖 png 就行，别的都不用动。


六、几种「看着没坏但没生效」的情况
----------------------------------
  - 名字对不上（多一个空格、全角半角不同、大小写不同）→ 这张图会被当成不存在，
    碎碎念就退化成随机抽，句子和图不搭。这是最常见的坑。
  - 图片不是 png（jpg / gif / webp）→ 认不出来，等于没有。
  - 表里写了、图删了 → 静默跳过，不报错。
  - JSONC 里漏了逗号 / 多了逗号 → 整份配置读不出来，她会退回出厂设置，
    所以改完存一次，看桌宠还正不正常。
  - 用记事本改完，确认是「UTF-8」编码保存（带不带 BOM 都行），别存成 GBK。


七、别动的地方
--------------
  - 别把整个 "memes" 段删掉（聊天配图和设置页的清单都靠它）；
  - 别改 memes 文件夹里其它文件名；
  - 别把图片放进子文件夹（只认 memes 这一层）。
